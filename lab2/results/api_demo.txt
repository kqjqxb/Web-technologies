
### Реєстрація користувача
POST /auth/registration
body: {"username":"user","password":"user1234"}
→ 201
{
  "message": "Користувача успішно зареєстровано",
  "user": {
    "id": "6afa33506daa60589aa53309",
    "username": "user",
    "roles": [
      "USER"
    ]
  }
}

### Повторна реєстрація з тим самим іменем
POST /auth/registration
body: {"username":"user","password":"user1234"}
→ 400

  "message": "Користувач з таким іменем уже існує"
}

      "value": "ab",

      "value": "1",
