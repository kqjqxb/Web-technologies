# Лабораторна робота №1. Протокол WebSocket. Використання Socket.IO для розробки чат-додатків

Чат реального часу з кімнатами: список учасників кімнати, системні повідомлення (вітання, вхід і вихід
учасника) та автоматичне повідомлення всім учасникам чату кожні 10 + N = 21 с (варіант N = 11).

| Файл | Призначення |
|---|---|
| `server.js` | HTTP-сервер Express + Socket.IO: кімнати, розсилка повідомлень, таймер автоматичних повідомлень |
| `utils/users.js` | Список підключених користувачів (вхід, вихід, учасники кімнати) |
| `utils/messages.js` | Формування об'єкта повідомлення (автор, текст, час, тип) |
| `public/index.html` | Сторінка входу (ім'я та кімната) |
| `public/chat.html` | Сторінка чату |
| `public/js/main.js` | Клієнт Socket.IO: приєднання до кімнати, надсилання і відображення повідомлень |
| `public/css/style.css` | Стилі (зокрема адаптивна верстка для мобільних) |
| `results/` | Скриншоти роботи чату, журнал автоматичних повідомлень |

## Запуск

```bash
cd lab1
npm install
npm start          # http://localhost:3000
```

Відкрити http://localhost:3000 у кількох вкладках/браузерах, ввести ім'я та однакову кімнату.
